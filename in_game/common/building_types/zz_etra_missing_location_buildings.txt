# Vanilla and DLC buildings that check for real-world locations missing from
# Etra's map. Each block is an exact copy of the vanilla definition except that
# `this = location:<missing>` is swapped for `always = no`, which clears
# "Invalid right side during comparison 'location'" without changing behaviour:
# on Etra's map those comparisons can never be true.
# Named zz_ so it loads after the vanilla and DLC files it replaces.
