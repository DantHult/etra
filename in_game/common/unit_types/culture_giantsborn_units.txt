# Giantsborn culture-group army line — full infantry + cavalry progression
# Parallel to vanilla tech line; gated by culture_group:giantsborn_group
# copy_from vanilla age templates (not elven half-strength). Artillery and auxiliaries remain vanilla.
#
# Overlay (consistent across ages; Battleborn already grants +20% HI power):
# HI: modest toughness/morale, paid with speed, food, and flanking
# LI: milder version of the same — still large people, not skirmish specialists
# LC: clumsy, hungry, poor shock; HC worse still. Nobles mercenary density lowered vs vanilla.
