# Ratfolk culture-group army line — full infantry + cavalry progression
# Parallel to vanilla tech line; gated by culture_group:ratfolk_group
# Uses ratfolk age templates: double max_strength, half combat_power (equal regiment mass)
# Cavalry overlays make mounted troops terrible. Artillery and auxiliaries remain vanilla.
